# AJ Leather Shoes Supply Order Manager

A single-file mobile web application built to simplify shoe supply order management. Designed for easy use on smartphones, allowing instant inventory updates via voice commands or quick text entry.

Created to help my mom manage her shoe business inventory directly from her phone without needing a laptop.

---

## Features

- Voice-to-text input via browser speech recognition
- Natural command parsing for updating shoe colors, sizes, quantities, prices, and branch names
- Real-time total quantity calculation
- Automatic daily date stamping
- Print-formatted layout scaled for single-page iOS/Safari PDF export

---

## Requirements

No installation or build process is required. The application runs directly in any modern web browser.

---

## How to Run

1. Clone the repository:
   git clone https://github.com/shashperera/shoe-order-app.git

2. Open `index.html` in any web browser.

---

## Usage Guide

1. Tap "Speak" and state your update out loud, or type it directly into the input field.
2. Tap "Apply" (or press Enter) to process the update.
3. Tap "Print/PDF" to output a single-page order document.

### Example Commands

- Change item color:
  Change AJ-036 colour to Brown

- Update branch location:
  Branch to Kandy

- Update quantity for a specific size:
  Change AJ-036 size 41 qty to 10

- Update item price:
  Price AJ-053 to 4200

- Add a new item entry:
  Add new item AJ-070 Black size 42 qty 10 price 3950
